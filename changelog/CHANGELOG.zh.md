# 更新日志

[English](CHANGELOG.md) | [中文](CHANGELOG.zh.md) | [返回使用说明](../README.zh.md)

了解 COROS MCP 的功能更新。

### 2026-09-21

- 支持 AI 根据体能和目标创建路跑、越野跑和骑行的训练计划及课程，并同步到 COROS；计划时长为 4–16 周。
- 未指定开始日期时保存到训练计划库或训练课程库；也可安排到训练日历，开始日期支持今天至未来 14 天。
- 支持通过 AI 查询和修改计划及课程；删除需在 COROS App 中操作。

### 2026-09-09

- COROS 已上架豆包插件目录，可直接添加，无需手动配置。

### 2026-08-27

- COROS 已上架 Workbuddy 连接器目录，可直接添加，无需手动配置。

### 2026-07-24

- COROS 已上架 [Claude 连接器目录](https://claude.ai/directory/coros)，可直接添加，无需手动配置。

### 2026-07-01

- COROS 已上架 [ChatGPT 插件目录](https://chatgpt.com/plugins/plugin_asdk_app_6a0694cbb2608191bbefb74ba810ab68)，可直接添加，无需手动配置。

### 2026-06-24

- 优化 Skill 登录和工具调用，适配无状态 MCP 接口。

### 2026-06-23

- 支持查询运动分段数据。
- 支持查询运动反馈和备注。
- 支持获取运动记录的 `.fit` 文件，包含 GPS 和逐秒数据；每天最多请求 50 个文件。
- 修复部分情况下运动汇总数据缺失的问题。
- 支持查询生理期数据。
- 支持查询压力时序数据。
- 支持查询健康快测时序数据。
- 支持查询睡眠 HRV 时序数据。
- 修复若干已知问题。

### 2026-05-19

- 支持跨区域登录，接入地址统一为 `https://mcp.coros.com/mcp`。

### 2026-05-09

- 支持通过 Skill 接入：`npm install -g coros-mcp`。

### 2026-05-05

首次上线，支持查询：

- 运动记录、运动汇总和训练日程。
- 体能指标：最大摄氧量（VO2max）、跑步表现、阈值配速和比赛预测。
- 训练状态：周训练负荷、训练量评估和恢复状态。
- 每日健康数据：步数、卡路里、运动时长、睡眠、平均心率、平均 HRV、平均压力和静息心率。
- 用户基本信息和已绑定设备。
