# COROS MCP Skills

[中文](README.zh.md) | [Home](../README.md) | [Getting started](../docs/en/getting-started.md) | [Tool reference](../docs/en/tools.md)

A collection of Agent Skills for COROS MCP.

## Skills

| Skill | Description |
| --- | --- |
| [`coros_mcp_login_gateway`](coros_mcp_login_gateway/) | Primarily intended for headless devices and similar environments. Handles login and regional routing through the global gateway, with tool discovery, tool calls and OpenClaw configuration. For general use, the official plugins or connectors listed in the [getting started guide](../docs/en/getting-started.md) are recommended. |

## Usage

Each Skill has its own directory. See its `SKILL.md` for scope, requirements and instructions. Keep its scripts and other dependencies alongside it.

Content installed through npm follows the published package version and does not automatically track updates to this repository.
