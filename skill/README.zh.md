COROS MCP 的 Agent Skill 集合。

## Skills

| Skill | 说明 |
| --- | --- |
| [`coros_mcp_login_gateway`](coros_mcp_login_gateway/) | 主要面向无头设备等运行环境，通过统一网关完成登录与区域路由，支持工具发现、调用及 OpenClaw 配置。建议优先通过[接入指南](../docs/zh/getting-started.md)中的官方插件或连接器接入。 |

## 使用

各 Skill 独立存放于对应目录。适用范围、环境要求与操作说明见目录内的 `SKILL.md`；使用时保留其脚本及其他依赖文件。

通过 npm 安装的内容以已发布包版本为准，不随本仓库更新自动同步。
